# 藤田琴音角色资料

中文显示名按用户要求使用“藤田琴音”，原文为“藤田ことね”。资料核对日期 2026-09-20。这是现有角色的非官方 AI 演绎；工程名仍为绮迹。日常称用户“制作人”是终端的互动约定，不意味着用户与角色存在现实合作。

- `BEHAVIOR.md`：中文表达、角色演绎和不确定性处理规则；其中语气示例为本项目新写，不是游戏原台词。
- `KNOWLEDGE.md`：带来源编号的精简知识卡，覆盖琴音及其他 12 位偶像，包含组合、姐妹、好友、学生会关系。
- `sources.json`：官方人物页、万代南梦宫制作人访谈、Re;IRIS 官方公告；每个编号可追溯到原文。
- `evals.json`：身份、关系误导、未知剧情、旧会话污染和日常语气的 12 个检查场景。

范围是基础人物档案与已核实的关系，不是全剧情资料库。2024 年访谈与 2025 年组合公告支持各自的事实，不能据此推断所有后续路线。没有收录的情节不从同人或玩家梗补齐；新增事实应先补官方来源，再更新知识卡。

运行 `python tools/build_kotone_persona.py`，将行为和知识合并到 `../SOUL.md`，去除朗读不需要的来源编号。官方 ai_agent 每轮读取该文件，因此知识实际进入系统提示，不是未接入的附属文档，也不是向量检索。生成器限制 UTF-8 小于 4000 字节，为共享的 8192 字节系统提示留出空间；不能无限扩充知识卡。`--check` 可检查生成文件是否过期。

新固件使用 `qiji_kotone_v1` 会话，保留旧 `qiji_chat` 记录但不把它当作琴音的聊天历史；长期记忆仍由官方 ai_agent 共用，若有错误身份记录，需另行核对。官方初始化只在 SOUL 不存在时写默认值，因此保留数据升级后需要运行 `python tools/deploy_kotone_persona.py` 更新已有文件。该工具只备份和替换 SOUL，读回比对，不触碰网络和 Key。

模型有随机性，提示词不能保证永不 OOC。板端会过滤回复中的中英文括号内容，避免将动作描写朗读；这也会略去普通括号补充信息，适用于本终端的简短口语输出。未闭合的括号尾部丢弃；全部被过滤则显示重试提示。角色的关系与语气仍需要实际多轮检查。
