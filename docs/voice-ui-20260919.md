# 语音优先界面与 ADB 检查

移除触屏文本输入框、发送按钮、屏幕键盘及其事件处理。顶部网络和对话状态合并到一行，长状态横向滚动；底部录音按钮由 32px 加高到 58px，点击开始、再次点击停止。角色和聊天区域向上扩展，根页面禁止滚动，避免拖动整个界面。保留 ADB `qiji_config ask` 用于诊断。

当前板上 R2 的 ADB 检查确认 `/etc/media/criteria.txt` 已更新，`mediad` 常驻且图初始化成功。板上保存的网络仍是出厂 SSID，现已重新配置到用户指定网络，取得 `192.168.5.158`；阿里域名 ping 两次均成功。阿里 ASR/TTS 已选择，Key 已恢复，时间已通过电脑 UTC 校准。

一次板端 TTS 诊断收到云端首段 PCM（日志 624ms），但播放图随后报 `volume@VolApb activate failed, ret -1163346256`，命令未在 40 秒内结束。错误码对应 FFmpeg `AVERROR_PATCHWELCOME`，播放仍未验收，不能因收到 PCM 宣称扬声器正常。此界面版本不包含该播放故障的修复，录音端到端也仍待验证。

构建沿用固定官方树和 R2 ROMFS 依赖修复。通用包 `qiji-chat-voice-ui.img` 不含用户凭据；本地调试包 `qiji-chat-voice-ui-2f-debug.img` 预置指定 Wi-Fi，不含云端 Key。界面更新需烧录后验收，未通过 ADB 热更新。
