# 绮迹酱 v0.3.0：图片动作、播放滚动与录音按钮

硬件仍为 Gemini-S1 / R528 + 2.8 寸 SPI，240×320 硬件竖屏。顶部 20px 状态轮播及北京时间/版本号保留，开发板 ENTER 仍开始/结束录音。

## 界面行为

- 中央角色改为 176×272 透明位图，待机、眨眼、倾听、思考、说话、开心、安慰、惊讶共 8 张；状态切图并有 2px 呼吸移动。说话帧每 260ms 与待机帧交替，不是音素驱动口型，也不是 Live2D。
- 底部半透明文本层保持 104px 高；右下角 44×44 圆形“录音”按钮浮在文本层上，录音中显示“停止”。正文右侧留出按钮位置。
- 收到首个 PCM 数据后按已接收 PCM 时长和经过时间近似推进文字。流尚未结束时用每秒约 4.5 字估算总时长，结束后使用 24kHz/16bit/单声道 PCM 字节数计算总时长。播放中上限 14px/s，避免晚到的时长导致倒退；播放后慢速循环阅读。
- 这是辅助阅读滚动，未取得播放器逐字时间戳或音频位置，不能宣称逐字同步。真机播放延迟、网络停顿和屏幕刷新仍需验收。

## 生成素材

参考图来自用户指定的藤田琴音文件，实际路径 E:/zxz12/Pictures/ktn/idol_3.png。按用户指定服务 https://sapi.riyuexy.cc/v1 调用图片编辑接口；模型列表只有 gpt-image-2，没有 image2.5。通过 imagegen 技能的 image_gen.py edit CLI，以参考图及每状态独立提示词生成。

请求参数为 1024×1024、medium；实际接口返回 1254×1254 RGBA 图片，保留返回原图和 alpha。这记录的是接口行为，未验证服务端实际模型实现。素材不属于项目原创角色声明或代码许可证范围，见 ../app/gemini_chat_minimal/ARTWORK.md。

- 原图与提示词：output/imagegen/kotone-v1，generation-plan.json 记录调用方式。
- 板端图片与二进制：assets/kotone-v1/bin，manifest.json 记录哈希及来源。
- tools/convert_sprite.py 用 alpha≥32 的边界忽略远处近乎透明的杂点，保留角色边缘 alpha，仅裁切、缩放并转换 LVGL9 RGB565A8，不生成动作。
- 每张二进制 143628 字节，8 张共 1149024 字节；固定目录 /resource/qiji/kotone。

## 复现

在固定官方树及基础音频修复上运行：

```sh
python3 tools/prepare_sprite_ui.py /home/vela/gemini-official-clean-20260919
cd /home/vela/gemini-official-clean-20260919
./build.sh vendor/allwinnertech/boards/r528/r528s3-gemini-s1/configs/qiji_chat/ -j4
source build/envsetup.sh
cd vendor/allwinnertech/lichee
source envsetup.sh
lunch_nuttx r528s3-gemini-s1
pack
```

prepare_sprite_ui.py 是累计入口，包含此前按键、触摸、语音及网络修复；缺任一张动作图片会阻止准备发布。--ui-only 只用于图片未齐时的代码编译，不用于最终交付。官方通用指南支持 Ubuntu 22.04，本地实际使用 WSL2 Ubuntu 24.04，属于官方支持范围之外的构建环境。

导出入口为 tools/export_portrait_release.py OFFICIAL_ROOT DELIVERY --sprite-ui；冻结源码、配置、补丁、图片、提示词、ELF、日志、SHA-256 和官方镜像校验结果。独立发布目录 firmware/sprite-ui-20260920，不覆盖此前冻结版本。

## 验证边界

主机测试覆盖触摸坐标、实体键消抖逻辑、播放前不滚动、播放中有界单调滚动、晚到时长和停顿恢复；使用官方 LVGL/FreeType 实际渲染界面。打包时逐张核对全部 8 张图片字节位于 res.fex，并校验启动组件和 ROMFS。

本版未在板子上烧录，实体按键、录音、扬声器、图片切换时的流畅度及音画配合仍需实物验收。历史版本的通过结果不代表本版已通过。

通用固件 qiji-chat-sprite.img 无 Wi-Fi 密码和云端 Key；本地调试 qiji-chat-sprite-2f-debug.img 含预设调试 Wi-Fi，不含云端 Key。格式化烧录会清除已有云配置，使用 tools/restore_board_config.ps1 恢复。旧 /data 中的 SOUL.md 会保留；新的角色外观描述只作为缺少 SOUL.md 时的默认值。
