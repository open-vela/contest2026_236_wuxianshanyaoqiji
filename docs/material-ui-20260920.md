# Material 图标与透明文本层

本次修改 qiji_layout.h、qiji_view.c，并添加官方 Material Icons Round 图标。保持项目中已有的分层动画实现。

- 文本框顶部从 y=200 下移至 y=216；高度从 104px 降到 88px。底部保持 y=304，与角色卡片间距仍为 8px；左右间距和同心圆角不变。
- 移除文本框和按钮的描边；按钮不加载默认主题边框、阴影或焦点轮廓。
- 录音按钮从 44×44 缩为 32×32，位置为 (184,264)；使用官方 24px mic、stop、more_horiz 圆角图标，无文字。点击范围向外扩 6px，保留约 44×44 触摸面积。
- 文本框背景由 80% 不透明降为 60%，按钮背景也为 60%；文字和图标保持不透明。提高的是背景透明程度，不是把文字一起淡化。
- 正文区域随文本框缩短自动计算高度，长文本继续滚动；为缩小后的按钮保留右侧空间。

图标来源、固定提交和许可证见 assets/material-icons/source.json、LICENSE。通过 tools/convert_material_icons.py 从官方 SVG 转为白色 RGB565A8 静态数组，无需运行时图标字体。界面预览使用项目真实 LVGL 渲染。
