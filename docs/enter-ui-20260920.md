# 绮迹酱 v0.2.0：实体 ENTER、时间和版本

适用 Gemini-S1 + 2.8 寸 SPI 屏，继承 240×320 竖屏候选版。

- 开发板 **ENTER** 实体键与触屏按钮共用录音状态转换：按一次开始，再按一次结束。
- 40ms 稳态消抖，长按不连发；启动时已按住的键不触发，必须先松开。忙碌或 AI 未就绪时丢弃本次按键，不排队。
- 顶部保持 20px 高，左侧状态轮播，右侧同时显示北京时间 `HH:MM` 和 `v0.2.0`。未校时显示 `--:--`；系统时钟仍保持 UTC，TLS 校验不受显示时区影响。
- 界面与 SOUL.md 中的助手名称统一为“绮迹酱”。

## 官方按键依据

固定 BSP 提交 `1676386193f0e710121e710935f1757c0f34b662`，对应文件：

- `vendor/allwinnertech/apps/factory_test/factory_test.c` 的 `test_button()`：Home/Enter/Menu/Vol+/Vol- 映射为 `0x10/0x08/0x04/0x02/0x01`，Enter ADC 约 34。
- `vendor/allwinnertech/chips/r528/drv/lradc/drv_lradc.c`：按硬件修订版本将 ADC 区间转换成按钮位掩码。
- `nuttx/drivers/input/button_upper.c`：读取返回当前 `btn_buttonset_t`，不是 Linux input_event。

应用每 20ms 非阻塞读取 `/dev/input/event1`，纯状态机处理稳态输入；仅官方驱动的逐次采样日志改为 `iinfo` 调试级别，避免每秒数十条日志积压。未改 ADC 电压区间或其他按键功能。触摸继续使用 `/dev/input0`。

## 构建与验收

固定官方源码及一次基础音频补丁之后，累计入口改为：

```sh
python3 /path/to/project/tools/prepare_enter_ui.py "$PWD"
./build.sh vendor/allwinnertech/boards/r528/r528s3-gemini-s1/configs/qiji_chat/ -j4
```

打包和完整镜像校验沿用 [构建指南](build-pack-guide.md)。新归档使用 `tools/export_portrait_release.py OFFICIAL_ROOT DELIVERY --enter-ui`，不覆盖既有竖屏归档。

主机测试在 `tools/portrait_preview` 中，`ctest` 覆盖触摸坐标及 ENTER 的启动按住、接触抖动、长按、忙碌事件消费、其他按键、时钟计数回绕。预览使用实际应用 LVGL 代码，不是真机照片。

![主机预览](assets/enter-ui/qiji-enter-idle.png)

板端旧版 SOUL.md 已备份并更新为新名字，ADB 回读校验相同；旧固件的一轮对话已验证回答包含“绮迹酱”并正常结束朗读软件流程。新固件也内置该人设作为首次启动默认文件。基础 bootstrap 会保留已有 SOUL.md，其他设备保留数据升级时需自行同步人设文件。

待新包烧录后验证 ENTER 的开始/停止录音、长按不重复、触屏与实体键交替操作、北京时间、Wi-Fi 校时，以及连续三轮语音。主机测试通过不代表上述实物验收通过。
