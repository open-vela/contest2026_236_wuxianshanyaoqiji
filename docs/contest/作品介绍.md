# 绮迹：原创角色语音陪伴终端

队伍：236 无险山妖气迹。方向：AI 硬件产品创新。材料日期：2026-09-19。

## 作品定位

绮迹面向学习、工作间隙想进行短时交流的人，以桌面小屏和语音交互提供轻量的原创角色陪伴。用户点一下按钮说话，再点一下结束，角色接收内容、生成回答并朗读。当前产品是开发板原型，尚未完成外壳与量产设计。

角色使用独立绘制的浅紫短发 Q 版形象，具备等待、聆听、思考、回复和异常状态动画。中文人设强调活泼机灵、喜欢被夸、认真努力，以简短口语适配小屏和 TTS。不是特定商业角色的官方产品，也未移植 Live2D。

## 技术实现

Gemini-S1 的 R528 运行 openvela / NuttX。2.8 寸 SPI 屏通过官方 LCD 后端显示，LVGL 渲染界面和角色。按钮触发工作线程，录音、网络和朗读不在 LVGL 事件回调中执行。

官方媒体服务采集音频，应用将 16 kHz 单声道数据流式送往阿里 Paraformer。识别文本经官方 ai_agent 的会话和消息总线送入豆包拟人模型，正式回复返回界面后由阿里 Qwen Audio 3.1 TTS 合成。播放端将云端 PCM 转换为固定硬件图需要的 48 kHz 双声道。

工程工作包括：核对官方小屏配置；修复媒体策略和增量 ROMFS 依赖；解决 NuttX 本地 socket 停止录音等待；修复进度提示抢占正式回复回调；处理播放 EOF；排查并修复录音空闲期间持续采集导致的音频积压。每项结论均记录对应版本和验证边界。

## 原型差异点与应用方向

将原创角色、可解释的交互状态与真实嵌入式语音链路结合，提供无需小屏打字的短对话体验。开发过程沉淀了可复用的 Gemini 语音排障 Skill、主机回归、设备验收工具以及带源码与校验信息的冻结成果。

目前尚无用户规模、付费转化或商业收入数据。潜在方向是桌面陪伴和角色互动硬件；下一阶段需要用户试用、成本测算和硬件外观设计来验证价值。

## 已验证与待验证

用户已确认小屏、基础文本对话和真实语音识别。前一版在板端完成两轮文本请求、模型回复和播放软件流程，模型耗时分别 889 ms 与 1274 ms，TTS 首块分别 585 ms 与 793 ms。这是两次样本，不能当作平均性能或端到端延迟。

当前 20:26:48 版本包含空闲采集修复和绮迹人设，已完成编译、主机回归与最终镜像验证。板端连续录音、实际听感、断网恢复和长时间稳定性仍待验收。本轮 ADB 已恢复，实读构建时间仍为 19:50:54，版本门禁未通过；需烧入最新候选镜像后继续。旧版 Wi-Fi 处于 RUNNING，媒体服务存活，阿里 Key 已配置，但时钟未校准。角色回复效果和物理扬声器输出也需现场确认。

## AI 辅助开发

AI 参与需求整理、官方源码阅读、代码修改、测试构建、设备日志分析与文档制作。典型方法是先定位链路阶段，再以真实源码和板端证据验证假设；将“构建成功”“主机测试通过”“实机软件流程完成”“物理声音可听”分开记录。

可复用 Skill 位于 `skills/gemini-voice-diagnosis/SKILL.md`。当前使用 Codex 辅助开发；本轮官方采集器清单未发现标准会话，真实 AI Coding 日志仍待按官方要求归集。既有其他工具的私有会话备份不随本次预提交上传。本说明不是原始对话日志。
