# 琴音与小澄：双硬件实机录像方案

建议录成约 4 分钟；按实际等待和朗读时长调整，不要求卡秒。这是本项目的拍摄建议，不是比赛官方时长要求。

2026-09-20 本次实测：修复小澄语音接口后，真实双机六次交替发言及总结全部得到设备确认，用时约 110 秒；不是脚本模式，语音开启。结束后两台在线，Gemini 空闲且没有录音；用户反馈声音没有重叠。22 项主机回归通过。证据见 `artifacts/duet-device-20260920/live-round-fixed.json` 和 `video-readiness.json`。本轮没有测试麦克风识别、实体停止按钮或冷启动，视频里须另行实际操作确认。

## 拍摄前检查

1. Gemini-S1 和 AI Passport 都正常开机，连同一 Wi-Fi。电脑保持联网、供电，关闭自动睡眠；协调服务必须持续运行。
2. 两台放在同一画面里，屏幕朝镜头，扬声器别被遮住。手机横向固定，锁定对焦与曝光，避免屏幕反光；先试录十秒检查文字和收音。
3. 在工程根目录运行 `python tools/duet/control.py status`，确认 `peers` 两项都为 true，`ready` 两项也为 true。服务须为真实 AI、有语音模式。若 Passport 刚结束单人对话，长按中键可切回双机模式并尝试开始；另一台未就绪时，再等就绪后长按。
4. 拍摄前先试完整一轮，确保两台都有外放、发言不重叠、两屏跟随文字、总结正常结束。听不到或文字没更新就先排查，不拿电脑预览代替实物。
5. 电脑若已经运行服务，不再启动第二个。确实没有服务时，在工程根目录运行 `python tools/duet/run_live.py --model character --manual`；本机已保存凭据，不需要在录屏里输入 Key。此命令会显示配对码，不拍这个终端。

## 推荐话题与启动方式

推荐话题：“忙碌之后，怎样用十分钟、不花钱放松一下？你们各提一个可选办法，最后由主人选择。”

长按 Passport 中键会用服务当前话题开聊；单人录音说的话不会自动变成双机话题。要确保使用上面的话题，可先让 Passport 进入双机就绪状态（若长按已开始一轮，可用下面的停止命令先结束），然后由镜头外的电脑运行：

```powershell
python tools/duet/control.py start --topic "忙碌之后，怎样用十分钟、不花钱放松一下？你们各提一个可选办法，最后由主人选择。"
```

该命令只发送话题和开始请求，不代替设备心跳或播放确认。要同时保存本轮证据：

```powershell
python tools/duet/control.py start --topic "忙碌之后，怎样用十分钟、不花钱放松一下？你们各提一个可选办法，最后由主人选择。" --wait --seconds 300 --report artifacts/video-take.json
```

已开始时不要再次 start，改用 `python tools/duet/control.py watch --seconds 300 --report artifacts/video-watch.json`。记录中的字幕来自模型真实输出；设备确认表示软件报告完成，不等同于麦克风录到了声音。

## 额外验收片段：停止与重开

建议单独录 30–60 秒，正片有余量再加入。开聊后按 Gemini 的 ENTER 或长按 Passport 中键停止；Gemini 当前短句允许播完。等停止生效、设备空闲后，再长按 Passport 中键重开，应开始新一轮，不重复上轮残留句子。这个片段必须现场实际成功后才放进“已验证功能”。

电脑应急停止：

```powershell
python tools/duet/control.py stop
```

不要通过拔电来演示正常停止。不要为拍摄临时烧录或清除配置。断网恢复、冷启动保留配置、连续十轮和长时间压力测试不纳入本次短视频的已验收声明。

## 拍摄与事实边界

- 完整交替发言和总结至少保留一份连续原始录像；展示版可以剪辑准备时间，但不要把失败跳过后称为一镜到底。
- 保留设备真实外放，不用后配音冒充设备声音；字幕按实际说话内容添加。
- 电脑协调服务、两块实体板和云端模型的作用要说明清楚，不称为完全脱离电脑、离线大模型或声音互相识别。
- 琴音是现有作品角色的非官方演绎，小澄为项目原创角色；不要把两者统称为原创角色。人物间硬件互动不属于游戏原作剧情。
- 镜头不拍 Key、Wi-Fi 密码或配对码。网页“播放脚本效果”是预览，不能当真实双机演示。

本轮设备测试结果单独保存在 `artifacts/duet-device-20260920`。初次新话题测试遇到小澄旧 `qwen3-tts-flash` 接口返回 HTTP 400 / Arrearage；协调服务已改为复用现有单人语音的 `qwen-audio-3.1-tts-flash` 后端。这不是预录音或脚本降级。云端额度未来仍需在录像前复核。
