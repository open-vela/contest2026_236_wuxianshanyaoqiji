# 原创角色素材记录

角色工作名：绮迹 · 紫丁香（Lilac），原创 Q 版女性角色。

本角色在本项目内以程序图形原创绘制，源文件为 qiji_avatar.c：浅紫短发、带高光的大眼睛、花瓣发夹、泡泡袖、蝴蝶结及紫丁香色小裙装。旧版种子精灵已保留在此前成果包内。
各层均是 LVGL 基础图形，不含下载的 Live2D 模型、动漫截图、第三方贴图或人物肖像，也未以指定现有角色为临摹对象。
没有引入 Cubism SDK 或 .moc3 文件，因此本实现属于 LVGL 分层角色动画。

角色动作：呼吸、眨眼、倾听、思考光点、收到文字回复后的笑脸，以及发夹上的错误提示色。
文字回复的笑脸不是音频口型同步。语音链路未验收成功，本次不宣称实现语音口型。

代码许可证按各源文件标注；角色素材的对外分发许可由项目权利人决定。本记录说明素材来源，不是法律上的绝对不侵权保证。
