# 原创分层角色对话试验

采用 LVGL 原生图形实现，未移植 Cubism SDK。角色是本项目原创“绮迹 · 种子灯”，素材来源记录见 `app/gemini_chat_minimal/ARTWORK.md`。

同一份角色 C 代码生成的预览：

![角色状态](assets/qiji-avatar-preview.png)

顺序为待机、倾听、思考、回复、错误。[动画预览](assets/qiji-avatar-animated.png) 包含实际绘图代码的呼吸和眨眼变化。
这是主机 LVGL 软件渲染预览，不是开发板录像，也不代表板端已达到特定帧率。

## 行为

- 屏幕左侧为小型角色舞台，右侧为可滚动的问答区域，底部保留输入及录音按钮。
- 角色每 3.2 秒呼吸一轮、约 4.7 秒眨眼一次；UI 每 100 ms 更新动画状态，不全屏播放视频。
- 提交文字显示思考光点，真实模型回复到达后露出笑脸；文字回复不自动调用尚未验收的语音服务。
- 录音成功后进入倾听状态；录音结束进入思考状态。错误时改变种子灯颜色。
- 没有用假的离线回答冒充豆包回复，也没有把文本动画称为音频口型同步。

## 构建与验收

沿用 `tools/prepare_wifi_doubao.py` 及官方 build.sh / pack 流程，继续使用固定小屏配置。
需要验证：冷启动亮屏、自动联网、角色动画、触摸键盘、拟人模型回复、长回复滚动和反复对话。
语音仍单独待验收。原可用镜像与旧成果 ZIP 保留，新镜像不能覆盖旧版本冒充既有验收。

预览复现：使用官方树 `apps/graphics/lvgl/lvgl` 作为 CMake 的 LVGL_SOURCE，构建 `tools/avatar_preview` 后运行其 render.py。
实际角色绘图和预览共用 qiji_avatar.c，未依赖第三方人物资产。
